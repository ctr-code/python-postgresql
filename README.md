# PostgreSQL and Python

Sample code for Code Institute's PostgreSQL and Python module, updated to work the the latest versions of the libraries and sample data (as of August 2026).

[Install script](https://github.com/lerocha/chinook-database/blob/master/ChinookDatabase/DataSources/Chinook_PostgreSql.sql) for Chinook sample database for PostgreSQL.  The [exact version](https://github.com/lerocha/chinook-database/blob/7f67772503d71ba90f19283c38e93923addb43fa/ChinookDatabase/DataSources/Chinook_PostgreSql.sql) used for this repo.

Install Pyscopg 2 with `pip install psycopg2-binary`.
